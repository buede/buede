That isn't decoration. It's the whole argument.

<details>
<summary><b>Where I stand</b></summary>

**Against enshittification.** Software should get better for the person using it, not slowly
worse in trade for someone else's quarterly number. The reliable defence isn't a promise, it's
architecture: keep the data on the user's device and there is no later moment where betraying
them becomes the profitable option.

**For AI, out loud.** I use it every day. Parts of this page were written with it. I'm not
going to hide that and I'm not going to apologise for it either.

**For neurodivergent users.** Not a cause I support from a comfortable distance. I built a
company on it, which means it's not a preference I get to quietly drop on the sprint where it
turns inconvenient. Short before long. Depth on request, never mandatory. No motion, no
ambiguity, no "you'll figure it out."

</details>
